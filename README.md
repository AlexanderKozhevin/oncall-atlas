# Атлас дежурств

Интерактивный русскоязычный лонгрид о ротации и эскалации IncidentRelay с учебными моделями и аудиогидом.

## Открыть

Откройте `index.html` в браузере или запустите из этой папки:

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8766. Сборка, npm-пакеты и сервер приложения не нужны. Все шрифты системные, зависимости и аналитика отсутствуют. Настройки моделей живут только в памяти страницы и сбрасываются при перезагрузке.

## Главы

1. `index.html` — выбор дежурного, приоритеты слоёв, ежедневная/недельная очередь, пробелы.
2. `replacements.html` — временные замены, границы окон, обмен, праздники.
3. `escalation.html` — политика и простой режим, ACK, решение, повторы, сбой доставки.
4. `simplify.html` — предложение удобного календаря и подтверждённых замен; не реализовано в IncidentRelay.
5. `alternatives.html` — концепты явных смен и общего диспетчерского поста; не реализованы в IncidentRelay.
6. `about.html` — проверенные источники и ограничения.

Аудио и расшифровки находятся в `audio/`. Озвучка синтезированная, на русском. Нативный плеер поддерживает паузу и перемотку. Аудио не управляет моделями и не запускается автоматически.

## Основание

Проверены реализация и документация локального IncidentRelay, базовый коммит `89e11d2707c0be366db2ea7de74b8aaa78a01584`, 2026-09-11. Источники перечислены на странице «Что подтверждено». Конфигурация production не проверялась. Исходники IncidentRelay не копировались в этот репозиторий. Здесь самостоятельная упрощённая реализация правил.

Все люди, даты смен, приоритеты и показатели нагрузки в примерах вымышлены. Сайт не подключён к IncidentRelay и не совершает действий с реальными дежурствами. Предлагаемые процессы маркированы отдельно от существующей логики.

В текущем коде напоминания политики используют задержку правила, минимум 60 секунд. Это отличается от краткой документации про интервал ротации. Простой режим проверяет достигнутый счётчик до отправки очередного напоминания, поэтому при интервале 5 минут и пороге 2 в модели переход происходит на 15-й минуте.

## Проверки

```sh
node --test test-model.cjs
node --check app.js
```

Тесты покрывают приоритеты и границы замен, отсутствие покрытия, суточный/недельный шаг, повторы и исчерпание политики, ACK, доставку, простой режим и недоступность резерва. Они проверяют учебную реализацию, не заменяют backend-тесты IncidentRelay.

## Публикация

Любой статический хостинг может обслуживать корень проекта. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → main → / (root), если это доступно для текущего тарифа и видимости репозитория. Сам факт приватности репозитория не означает приватность Pages-сайта. Публикация должна быть осознанным отдельным действием.

## Видео
